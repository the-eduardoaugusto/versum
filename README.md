# Versum

Bible reading app with TikTok-style vertical feed. Focus: intentional reading, consistency, no toxic algorithms.

## Reading Modes
- **Discovery:** Random verses/chapters, no repeats
- **Journey:** Genesis → Revelation, sequential, auto-saved progress

## Interactions
Like verses | Like chapters | No highlights/annotations (intentional)
Likes: private by default, metrics opt-in

## Social
Follow users | Friends feed (liked content only) | No comments/reposts/public metrics

## Stack
Next.js 16 + React 19 | Hono + Drizzle ORM + PostgreSQL | Magic Link auth + infinite session | Bun
