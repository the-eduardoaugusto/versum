# Tooling

## Package Manager & Runtime

Use **bun** as both the package manager and runtime.

- Install deps: `bun install`
- Run scripts: `bun run <script>`
- Execute files: `bun <file>`
- Never use `pnpm`, `npm`, or `yarn` unless the project explicitly requires it for a specific workspace or tool incompatibility.
